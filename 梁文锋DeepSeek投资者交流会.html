一、企业底层愿景：善意驱动，克制为长期核心战略

1. 创业初心与管理逻辑

  • 创始团队初期无上市、逐利目标，初衷是AI具备长期人类价值，以善意做技术；团队仅为普通从业者，并非天才团队。
  • 不靠KPI、规章制度管理，依靠统一愿景凝聚全员；愿景无成文标语，落地在实际业务行为中。
  • 核心判断：AI长期市场规模可达全球GDP10%，试图独占行业收益必然被淘汰，克制是顶层长期战略。

2. API定价逻辑：只赚合理利润，拒绝利润最大化

  • 定价标准：服务器硬件10个月收回成本，对应6倍合理收益，存在充足降价空间。
  • 案例：DDCP模型主动降价至原价1/4，内部全员认可；即便涨价一倍用户需求几乎无衰减，仍坚持低价普惠。
  • 暂不继续降价原因：当前价格已覆盖绝大多数用户，降价无法提升需求与社会价值。

3. 商业化取舍：C端、B端只是AGI副产品

  • 去年C端流量爆发未借机变现、不打造超级App与大厂竞争，不抢夺短期流量红利。
  • B端API远期ARR有望达数亿美金，现金流可覆盖全部研发成本，但不作为公司第一优先级。
  • 战略定位：C/B端是“芝麻”，AGI是核心“西瓜”，不分散核心研发资源深耕短期商业化。

二、开源战略：主动自愿开源，与商业化无冲突

  • 开源为主观选择，区别同行被动开源；主力最强模型全部开源，开源版本与商用模型完全同质，不阉割能力。
  • 核心壁垒不在模型权重，而在整套训练、推理工程优化与极致低成本部署能力，同行难以复刻。
  • 10个月回本定价体系下，第三方独立部署成本更高，开源不会冲击自有API业务。
  • 主动为同行提供部署技术支持，市场空间足够大，无零和博弈思维，愿意赋能阿里、智谱等竞品。

三、四阶清晰AGI技术发展主线

完整演进路径：基础语言大模型 → CoT思维链（已落地）→ Agent智能体（当前主攻）→ 持续学习（全球瓶颈）→ 模型自我迭代奇点 → 具身智能（机器人）

1. 各阶段技术现状

  1. CoT思维链：已完成，奥数、代码能力超越顶尖人类；
  2. Agent智能体：当前核心迭代阶段，拓宽任务边界，短板为无法长期持续学习；
  3. 持续学习：下一代核心突破点，全球暂无成熟落地方案；突破后模型可自主迭代下一代大模型；
  4. 奇点：渐进式发展，实现自我迭代后AI可辅助研发具身智能；
  5. 具身智能：最终目标，解决现实物理交互、人力替代需求。

2. 研发资源取舍

  • 视频生成、3D、通用世界模型不属于智能主线，短期不投入核心算力人力；
  • 多模态仅作为配套组件，V4系列将支持原生多模态，但非研发主线；
  • 坚定相信Scaling缩放定律，模型规模越大能力越强，国内算力不足是唯一限制。

四、算力硬件：国内最大短板，国产芯片迎来替代机遇

1. 国内外核心差距

  • 人才无本质差距，差距仅来自算力资源；算力不足限制实验，间接拉开人才实践差距。
  • 现有算力约2万张H等效英伟达卡；华为950仅分配1.6万张，等效仅4000张英伟达B系列卡，不足以训练超大模型。
  • 海外训练800B激活模型需5万GB300/20万华为950卡，国内当前算力存在数量级差距。

2. CUDA护城河瓦解三大因素

  1. AI可自动生成底层算子代码，快速搭建完整生态；
  2. 自研TileLang高级编译语言，完整替代CUDA算子开发；
  3. AI专用计算卡与游戏卡解绑，不再绑定CUDA生态。

3. 华为950芯片优劣势

  • 优势：性能可平替英伟达GB200/GB300，全任务兼容；
  • 短板：4张华为卡等效1张英伟达、硬件迭代落后2年、价格溢价50%-100%；
  • 预判：1年内国产芯片生态问题完全解决，短期瓶颈为产能，5年内产能约束大幅缓解。

4. TileLang技术价值与算力采购策略

  • V3模型已脱离英伟达CUDA生态，基于TileLang运行，可无缝迁移国产卡；短期仅1%-2%性能损耗，长期大幅提升效率。
  • 融资资金优先全部采购GPU，合理价格下有多少收多少；半年内花完资金采购算力为最优结果。
  • 硬件折旧：英伟达卡5年生命周期，华为卡仅3年；优先外部采购芯片，仅渠道受阻才自研芯片。

五、组织管理：无KPI双轨科研团队，团队稳定为唯一核心利益

1. 双轨工作机制

  • 自上而下正式协同项目：占用员工时间不超过50%；
  • 自下而上自由探索：剩余一半时间员工自主研究，无考核、无任务约束，鼓励前沿创新。

2. 团队稳定是第一底线

  • 公司最大风险为人才流失；只要核心团队稳定，资金、算力均可解决，AGI仅为时间问题。
  • 本次融资大幅提升核心员工期权，人员流动率远低于行业；员工核心诉求是参与AGI研发，而非薪资。
  • 企业文化：极少加班，高度聚焦主线业务，主动砍掉非核心工作。

3. 决策与组织扩张规划

  • 重大决策依靠团队共识，无模仿对标企业，区别于无商业化压力的贝尔实验室；
  • 人员扩张后分层调整：职能部门搭建严谨层级，研发团队维持扁平松散结构。

六、行业终局与产业格局预判

1. 终局三大核心竞争差距（成本为第一壁垒）

  1. 成本（中国企业天然结构性优势）；
  2. 技术落地时间；
  3. 用户产品体验。

2. 国内产业收敛趋势

  • 当前国内基础大模型厂商过多，资源分散；长期收敛至3-4家通用基础模型企业，行业走向薄利普惠，无长期暴利。
  • 中国长期定位全球AI产能中心，依靠极致成本输出低价模型，工程、产品体验具备优势。
  • 竞争规律：追求高额利润的企业，会被只赚取合理收益的玩家击败。

3. 全球头部厂商竞争

OpenAI、Anthropic、Google交替领先，不存在长期一家垄断；Anthropic代码优势仅为短期先发红利，将快速被追赶。

七、商业化、资本平衡与研发难点

1. 商业化路径规划

  • B端API增长乐观，远期有望实现净利润；即便技术停滞，仅靠API业务即可支撑上市，具备稳定商业底盘。
  • 现阶段优先通用Coding Agent，金融、医疗等垂直行业应用交给合作伙伴，不做全产业链垂直整合。
  • 不深耕广告、电商、本地生活等短期变现业务，判断产品生命周期短，投入性价比极低。

2. 核心研发难点

  • 持续学习：全球无成熟方案，资源消耗极低，全员常态化思考探索即可，无需大量算力人力；优先级高于垂直行业模型。
  • 高质量数据标注：国内外成本无差距，国内布局晚是短期能力短板；一半核心研究员自主参与低成本标注，1年内短板大幅缓解。
  • 模型幻觉：属于产品侧问题，可通过后训练优化改善，非当前核心研发优先级。

3. 数据边界判断

模型可依靠仿真、自生成数据突破人类真实知识上限，类似AlphaGo走出人类未知棋路，不受历史真实数据限制。

八、其他关键补充观点

  • 发版节奏：舒适迭代周期为2-3个月一版，V4多模态版本仍有大量优化空间；
  • 人才周期：AI人才短缺仅阶段性现象，2-3年内快速缓解；国内模型厂商持续出清，资源集中；
  • 国产算力前景：短期产能受限，5年后产能约束大幅缓解，长期看好国产芯片完整替代；
  • 研发优先级：模型第一目标是服务内部研发、加速下一代模型迭代，其次才对外服务用户。
